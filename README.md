# 📄 Scientific Paper Peer Review Automation
-------
An automated, multi-agent peer-review workflow for **2ndOpinion Desktop**. This workflow processes a scientific manuscript PDF, extracts its core claims, searches literature databases (PubMed & web) for novelty and prior evidence, evaluates whether the reported data justifies each claim, and synthesizes a structured peer-review report.

## 📌 About This Automation
The **Paper Peer Review** automation performs an in-depth, multi-stage scientific evaluation of any manuscript:
1. **Claim Extraction:** Parses the input PDF and identifies the 3 central scientific claims made by the authors.
2. **Literature & Novelty Search:** Queries PubMed and live web search for each claim to determine prior art, novelty, and potential conflicting literature.
3. **Evidentiary Support Reasoning:** Analyzes the experimental controls, sample sizes, and measurements reported in the manuscript against standard evidentiary bars.
4. **Final Synthesis:** Combines individual claim evaluations into a structured peer-review report detailing major and minor points with actionable feedback for authors.

## 🚀 How to Use
### Step 1: Install 2ndOpinion Desktop
1. Download and install **[2ndOpinion Desktop](https://2ndopin.io/desktop)** for macOS or Windows.
2. Launch 2ndOpinion and navigate to the **Automations** tab from the main sidebar.
### Step 2: Import the Automation
1. Download `Paper_peer_review.automation.json`[link](https://github.com/al2na/peer_review_automation/blob/496818e02693187d0729c5529de13b8f88d46756/Paper_peer_review.automation.json) from this repository.
2. In 2ndOpinion Desktop, click **Import Automation** (or the **Import** button in the Automations sidebar).

<img width="589" height="68" alt="image" src="https://github.com/user-attachments/assets/bbe5d05b-9e53-4fdb-b27c-f5484af5bdb2" />
3. Select `Paper_peer_review.automation.json` to load the graph workflow onto your canvas.
### Step 3: Run the Automation with your PDF
1. Switch to **Run Mode** on the automation canvas.
2. In the **Run Parameters** panel (or on the `paper PDF` input node), click **Choose file** and select the manuscript PDF you want to review.
3. Click **Run** to execute the pipeline.
